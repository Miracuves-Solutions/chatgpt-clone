## How It Works

1. User signs up for the SaaS platform and selects a subscription plan
2. User accesses the AI chat interface with customizable prompt templates
3. User selects preferred AI model (GPT-4, Claude, Gemini, or open-source)
4. AI processes the request with context from the selected knowledge base
5. Usage is tracked against the subscription tier limits
6. Admin panel monitors usage, billing, and customer accounts

## Architecture

```mermaid
flowchart LR
    A[Flutter Apps<br/>Android · iOS] --> G[REST API<br/>Laravel Backend]
    W[Web Platform<br/>Responsive] --> G
    P[Partner Panel] --> G
    AD[Admin Dashboard] --> G
    G --> DB[(MySQL)]
    G --> S3[Object Storage]
```

**Stack:**

| Layer | Technology |
|---|---|
| Web Platform | React.js with real-time streaming |
| Backend API | Node.js + Express |
| Database | MongoDB |
| AI Layer | OpenAI, Anthropic, Google AI, open-source LLMs |
| Vector Store | Pinecone / Weaviate for knowledge base |
| Real-time | Server-Sent Events for streaming responses |
| Payments | Stripe, Razorpay for subscription billing |
| Cloud Hosting | AWS / DigitalOcean / Contabo VPS |
